# memories/

Contexto persistente del proyecto Certify: todo lo que no se deduce leyendo el codigo
y que se perderia entre sesiones o personas. **Leer esto antes de trabajar en el proyecto.**

## Como usar esta carpeta

- Antes de empezar: leer `conocimiento.md` (reglas y trampas) y lo reciente de `historial.md`.
- Al tomar una decision de diseño o de herramientas: agregar una entrada a `decisiones.md`.
- Al terminar un cambio relevante: agregar una entrada a `historial.md` (fecha, que, por que).
- Si un dato aqui deja de ser cierto: corregirlo o borrarlo, no dejar contradicciones.
- Fechas siempre absolutas (AAAA-MM-DD), nunca "ayer" o "la semana pasada".
